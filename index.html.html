Arquitetura Pronta para Microsoft 365

⚡ Sincronização Power Automate & SharePoint

Este painel já estrutura todos os checks, responsáveis, tempos e histórico em formato padronizado para listas do SharePoint via Power Automate (gatilho HTTP). Além disso, se o ambiente possuir nuvem ativa, a sincronização entre os operadores já ocorre automaticamente em tempo real.

Sempre que clicar em "Sincronizar Tudo" (ou automaticamente a cada check), o sistema enviará o payload JSON consolidado para este fluxo.
Permite que a dashboard busque os checks salvos na lista do SharePoint ao abrir a página.
